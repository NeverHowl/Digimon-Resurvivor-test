## 1. 데이터 조각 오경보 수정
v0.18.5의 바이러스/백신/데이터/진화 카드가 EVO를 "올렸다가 되돌린 뒤 다시 지급"해서 EP 감소로 오인되던 문제입니다.
카드가 `grantEvo`를 직접 호출하도록 바꿔, 올렸다 내리는 과정을 없앴습니다. `grantEvo`는 EVO를 줄이는 일이 없게 했습니다(퇴화 양도로 999를 넘은 EVO가 카드로 깎이는 경우 포함).

## 2. 치명 퇴화
- 하위 진화체가 있는 디지몬의 HP가 0이 되면 성장기로 퇴화합니다. HP는 성장기 최대 HP의 50%, 1초간 무적입니다.
- EVO는 그대로 유지됩니다. 패시브는 성장기 것만 남고 Lv1로 돌아갑니다(수동 퇴화와 같은 이력 계산).
- 어디로 퇴화하는지는 개체의 경로(3단계)가 정합니다. 정규 루트는 자기 성장기, 상점 영입 개체는 영입 때 정해진 경로의 성장기입니다(성장기가 하나뿐이면 그것, 여럿이면 정규 루트, 모두 비정규면 영입 때 무작위로 한 번 정해 저장).
- 전투 중이므로 진화 연출과 진화 BGM은 재생하지 않습니다. 화면 효과와 메시지만 나옵니다.

## 3. 전투불능
- 퇴화할 수 없는 개체(성장기, 경로 불명 개체)의 HP가 0이 되면 전투불능이 됩니다.
- 회색으로 그 자리에 멈추고, 자동으로 다른 디지몬으로 태그됩니다. 태그 키로 전투불능 개체를 고를 수 없습니다. 파티에서 빠지지 않고 디지에그도 남기지 않습니다.
- 회복 데이터 선택 화면과 레벨 보상 대상에 전투불능 개체가 나옵니다. HP가 최대 HP의 50% 이상이 되면 자동으로 복귀합니다(무적 1초). 50% 미만이면 전투불능이 유지됩니다.
- 파티 전원이 전투불능이면 게임오버입니다. 기적 유물이 있으면 기존 기적 부활이 발동합니다(최근 파티의 최고 진화체로 새 개체 부활, 1회).
- 영구 사망(파티 이탈 + 디지에그)은 이 경로에서는 더 이상 일어나지 않습니다.

## 4. 기록
- 치명 퇴화는 `퇴화` 이벤트(`mode: lethal`)로, 전투불능은 `전투불능`, 복귀는 `전투 복귀`로 남습니다. 이 변화들은 이상징후(EP·성장 수치 감소)로 잡히지 않습니다.

## 확인한 범위 (Chromium, 자동)
- 치명 퇴화: 자연 진화 개체와 상점 영입 개체(워그레이몬) 모두 성장기로 퇴화, EVO 유지, 경로·이력 정리, HP 50%, 무적 1.0초(게임 시간) 후 피격.
- 전투불능: 정지, 자동 태그, 태그 키 건너뜀, 회복 25%에서는 유지·50%에서 복귀, 회복 선택 화면에 표시, 전원 전투불능 시 게임오버, 기적 보유 시 부활, 경로 불명 개체(무겐드라몬)는 전투불능.
- 회귀: 진화 경로 해시(자연 -220519920 / 퇴화 76083092) 동일, 구매 검사, 복구 8종, 기록 R1~R7, 시나리오 12개(변경은 기적 시나리오의 이벤트 순서뿐: 사망/이탈 → 퇴화/전투불능), 85초 플레이 오류·감사·경보 0, 보상 선택 시 `evo` 기록 확인.
- 확인하지 못한 것: 회색 표시의 실제 모양(이미지 파일이 없는 환경), 실제 Edge, 모바일 기기, 장시간 플레이.

## 알려진 한계 / 직접 확인해 주세요
1. 전투불능 개체는 그 자리에 고정됩니다. 전원 전투불능 직전의 상황에서 적이 전투불능 개체에 닿는 판정은 없습니다(피격은 조작 중인 개체만 받는 기존 구조).
2. 능력치·투자는 수동 퇴화와 같은 방식으로 처리됩니다. 따로 깎는 규칙은 넣지 않았습니다.
3. 체험장은 원래 피해를 받지 않아 치명 퇴화가 일어나지 않습니다.
4. 수동 퇴화 버튼은 그대로이며, 같은 경로·패시브 규칙을 씁니다(3단계에서 이미 맞춤). "단계 선택 후 대상 선택" 방식은 넣지 않았습니다.
