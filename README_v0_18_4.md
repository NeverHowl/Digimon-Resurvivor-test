# 디지몬 RE:서바이버 v.0.18.4 (3단계: 개체별 경로 분리)

v0.18.3a 기준 패치입니다. 개체마다 "어떤 경로로 이 형태가 되었는가"를 따로 기록합니다. 전투불능·치명 퇴화(5단계)의 선행 작업입니다.

시작 화면에 `v.0.18.4 · 3단계 경로 분리`가 보이는지 확인하세요. 이전 버전이면 Ctrl+Shift+R.

## 바뀐 것

1. **개체별 경로 3개 필드** (모든 개체가 생성될 때 정해지고 저장됩니다)
   - `routePath`: 출발 성장기에서 현재 형태까지의 경로. 퇴화 후보를 이 경로에서 읽습니다.
   - `peakPath`: 지금까지 도달한 가장 높은 경로. 기적·치명 퇴화용(5단계에서 사용).
   - `routeKind`: `regular`(정규 루트) / `chosen`(지정 루트) / `unknown`(경로 불명).
2. **경로 정하는 규칙.** 성장기는 자기 자신입니다. 상점 영입·고단계 시작 개체는 "각 형태의 첫 번째 진화 분기만 따라가는 경로"가 있으면 그것(정규)을 쓰고, 없으면 가능한 경로 중 하나를 무작위로 한 번 정해 저장합니다. 진화 트리에 없는 형태(예: 무겐드라몬)는 `unknown`입니다.
3. **진화·퇴화에 따라 경로가 갱신됩니다.** 진화하면 경로 끝에 붙고, 퇴화하면 그 지점까지 잘리며, 최고 경로는 퇴화해도 유지됩니다. 경로 밖 형태로 진화하면 실제 진화를 기준으로 이어 붙입니다.
4. **패시브는 그대로입니다.** 패시브 레벨은 기존처럼 `v014History`(실제 진화 이력)로 계산합니다. 상점 영입 개체는 이력에 자기 자신만 있으므로 패시브가 이전 버전과 같습니다. 퇴화하면 이력이 경로의 그 지점까지로 줄어 패시브도 내려갑니다.
5. **수동 퇴화가 경로를 읽습니다.** 그래서 **상점 영입으로 얻은 고단계 개체도 상태창의 "퇴화 · 진화포인트 양도" 버튼이 생깁니다**(전에는 진화 이력이 한 칸뿐이라 불가능했음). 양도 EVO는 정가(80/135/180/400) 합산 그대로입니다.
6. **복구·기록 연동.** 세 필드는 보호 대상 성장 항목에 포함되어, 복구(v0.18.3a) 때 함께 되돌아갑니다. 런 기록 상세에 "계통 경로 · 최고 도달"이 표시됩니다.
7. **안전장치 준비.** `unknown` 경로 개체는 퇴화 대상이 아닙니다(5단계에서 이 개체는 퇴화 대신 전투불능으로 처리합니다).

## 확인한 범위 (Chromium, 자동)

- **자연 진화 23개 계통 전체**(8종 시작 성장기에서 끝까지)를 이전 버전과 같은 순서로 진화시켜, 패시브·능력치·계통 속성이 담긴 결과가 이전 버전과 일치(해시 동일). 경로는 모두 진화 이력과 같습니다.
- **수동 퇴화 25건**(계통별 모든 단계)이 이전 버전과 결과 일치: 형태, 이력, 능력치, EP 이전량.
- 상점 영입형 28종 경로 검사: 유효하지 않은 경로 0, 정규 18, 지정 9, 불명 1(무겐드라몬). 한 번 정해진 경로는 다시 읽어도 같습니다.
- 상점 영입 워그레이몬/메탈가루몬/가루다몬: 퇴화 버튼 표시, 성장기까지 퇴화(EP 395/395/215 양도, 식별번호 유지), 최고 경로 유지, 재진화 후 경로 일치. 상태창 목록에 퇴화 후보 6개가 정확히 나옵니다.
- 기존 시나리오 12개, 기록 보강 시험, 복구 시험(8종), 85초 일반 플레이: 모두 이전과 동일, 오류·감사·경보 0.
- 확인하지 못한 것: 실제 Edge, 모바일 기기, 장시간 플레이.

## 알려진 한계 / 직접 확인해 주세요

1. 같은 개체의 경로가 여러 개인 형태(스컬그레이몬 등 비정규 분기)는 첫 영입 때 무작위로 정해져 저장됩니다. 의도한 경로와 다르면 알려 주세요(정규 규칙을 바꾸면 됩니다).
2. 이 버전에서 퇴화는 여전히 **수동 버튼**입니다. 치명 퇴화와 전투불능은 5단계입니다.
3. 이미 진행 중이던 런의 개체에는 경로가 없으므로, 이 패치 적용 후 처음 필요할 때 현재 형태 기준으로 만들어집니다. 새 런부터 정확합니다.
