# 디지몬 RE:서바이버 v.0.18.3a (복구 장치)

v0.18.3 기준 패치입니다. 게임 동작과 수치는 바뀌지 않았습니다. **초기화·유실이 감지되면 화면의 "복구하기" 버튼으로 해당 디지몬을 직전 정상 상태로 되돌리고 런을 이어갈 수 있습니다.**

## 적용 (파일 3개)

| 파일 | 처리 |
|---|---|
| `index.html` | 덮어쓰기 |
| `patch.js` | 덮어쓰기 |
| `sprite_data.js` | 변경 없음 |

시작 화면에 `v.0.18.3a · 복구 장치`가 보이는지 확인하세요. 이전 버전이면 Ctrl+Shift+R.

## 동작

1. **복구 시점 저장.** 런 중 개체마다 약 1초 간격으로 성장 상태(진화체·이력, EP, 투자, 속성 포인트, 특화, 유물, 메모리, 능력치 등)를 최근 15개까지 보관합니다. 서버 전송은 없고 메모리에만 있습니다.
2. **이상 감지 시 동결.** 변경 감사, 성장 수치 감소, 보호 장치 개입이 잡히면 해당 개체의 저장을 멈추고, 감지 0.4초 전까지의 마지막 상태를 복구 시점으로 고정합니다.
3. **알림.** 실제로 낮아진 값이 있을 때만 화면 왼쪽 위에 "⚠ 초기화·유실이 의심되는 디지몬 N마리 [복구하기] [무시]"가 계속 표시됩니다. 값이 정상으로 확인되면 몇 초 뒤 저절로 사라집니다.
4. **복구 창.** 개체마다 "현재 → 복구" 값을 보여 줍니다. "이 디지몬 복구", 여러 마리면 "모두 복구", 방금 복구 "되돌리기"가 있습니다.
   - 진화체가 낮아졌으면 그 시점의 진화체로 되돌립니다(능력치도 그 시점 값). 같은 식별번호를 유지하고 파티 위치와 조종 중인 디지몬도 유지됩니다.
   - 진화체는 그대로고 EP·투자·특화 등만 낮아졌으면 **낮아진 항목만** 올립니다. 복구 시점 이후 얻은 성장은 유지됩니다(현재와 저장값 중 높은 쪽).
   - 파티에서 사라진 개체는 다시 넣습니다. 자리가 없으면 내보낼 동료를 고르게 합니다.
   - 진화로 EP를 쓴 경우는 EP 복구 대상에서 제외합니다.
5. **복구도 명령입니다.** 복구는 `restore` 명령으로 기록되어 변경 감사에 걸리지 않고, 런 기록에 "복구 · 어떤 항목 · 게임 시간 기준"이 남습니다. 복구 직후 같은 이상이 다시 잡히지 않습니다.

## 제한

- 보상·선택 화면이 열려 있으면 복구할 수 없습니다(그 화면이 옛 개체를 붙잡고 있을 수 있어서). 화면을 닫은 뒤 누르세요.
- 능력치 등 진행 항목이 아닌 값은 복구 시점 이후 변화가 사라질 수 있습니다(진화체가 되돌아가는 경우). 복구 창에 복구 시점이 표시됩니다.
- 파티에서 사라진 개체 복구는 "되돌리기"를 지원하지 않습니다.
- 자동 복구가 아니며 원인을 막지는 않습니다. 같은 일이 재발하면 기록에 쌓입니다.
- 이미 끝난 런(게임오버)에서는 복구할 수 없습니다.

## 변경 위치 (`patch.js`)

- 새 함수: `dsReset`, `dsMax`, `dsFields`, `dsSample`, `dsTick`, `dsFlag`, `dsCandidates`, `dsBuild`, `dsPin`, `dsRestore`, `dsRollback`, `dsPoll`와 알림·복구 창 UI
- 수정: `rhTrace`(이상 시 동결), `rhEvent`(blocked 연결), `rhEventText`('복구' 표시), `update`·`initGame` 래퍼, 버전 상수
- 테스트 훅 `window.__dr.ds`(`?drtest=1`일 때만)

## 확인한 범위 (Chromium, 자동)

- 직접 만든 초기화 상황 8종: EP·투자 초기화 → 알림·복구·되돌리기, 진화체·능력치·이력 초기화 → 교체 복구(식별번호·파티 위치 유지)와 되돌리기, 사라진 개체 복귀(빈 자리/가득 찬 파티에서 대상 선택), 선택 화면이 열려 있을 때 차단, 저장 개수 상한·동결·알림 자동 해제, 진화 직후 EP 오인 없음, 저장 비용(약 0.03ms).
- 복구 후 감사·경보 추가 없음, 페이지 오류 0.
- 기존 시나리오 12개와 기록 보강 시험은 v0.18.3과 결과 동일. 일반 플레이 85초에서 알림이 뜨지 않음(오탐 0).
- 확인하지 못한 것: 실제 초기화 버그 상황(재현 불가), Edge, 모바일 기기, `assets` 환경의 그림.
