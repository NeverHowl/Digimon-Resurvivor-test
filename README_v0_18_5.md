# v0.18.5 — 4단계 EVO 정리 + 체험장 진화 BGM

## 변경
- 처치로 얻던 EVO 전부 제거(영입 엘리트 +12, 구 +35/+50). 지급 후 복구가 아니라 지급 자체를 삭제.
- `grantEvo(c, amount, source)` 단일 창구. 보상/카드 지급은 모두 여기를 거치며 추적 기록(`evo`)에 남음.
- 플롯몬 계열 조숙: EVO 획득량 +10/15/20/25%(레벨별). 필요량은 정가. 퇴화 이전/합체/기적 복구에는 미적용. 기존 `ownedPassives.precocious` 강제 부여 제거.
- 단계 건너뛰기 EVO 비용: 단계 차이 합산으로 일반화(명시된 기존 비용은 그대로).
- 체험장에서도 진화/퇴화 후 진화 시 bgm_evo.mp3 재생. 체험 시작 세팅 중에는 무음.
